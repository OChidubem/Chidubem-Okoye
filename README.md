# HuskyPark — Part 4 (Source Control + Azure Deployment Preparation)

This repository now includes a complete **Part 4 submission kit** to help your group satisfy the rubric requirements:

- Source control setup checklist and collaboration workflow
- Azure deployment transition plan
- PDF report content template (member contributions + technical plan)
- 5-minute video demo script/checklist

> If this repo will be your official class repo, make it private and invite all team members as collaborators before recording your demo.

## Quick Start

1. Review `docs/part4/source-control-checklist.md` and apply each item in your GitHub settings.
2. Follow the branch and pull request workflow in `docs/part4/version-control-workflow.md`.
3. Complete and export `docs/part4/report-template.md` to PDF.
4. Rehearse using `docs/part4/video-demo-script.md` and record your 5-minute video.
5. Commit all artifacts (including DB scripts) so your commit history shows real collaboration.
