# 5-Minute Video Demo Script (Part 4)

Keep the demo fast and rubric-aligned.

## Suggested Timeline

### 0:00–0:30 — Intro
- Team and project name.
- Goal of this phase (source control + Azure deployment readiness).

### 0:30–2:00 — Repository Setup
Show:
- Private repository setting.
- Collaborators/team members.
- Branch list and naming convention.
- Branch protection rules.

Narration tip:
- Explain *why* these choices improve collaboration and quality.

### 2:00–3:20 — Version Control in Practice
Show:
- Commit history with multiple contributors.
- Example PR with review comments and approval.
- Database scripts committed in version control.

Narration tip:
- Highlight teamwork evidence and iterative commits.

### 3:20–4:40 — Azure Deployment Preparation
Show:
- Deployment plan document.
- Components to deploy (app/backend, database, configs).
- Azure services selected and Dev/Prod flow.

Narration tip:
- Keep architecture explanation simple and concrete.

### 4:40–5:00 — Wrap-up
- Summarize readiness.
- Mention that final deployment demo will be provided in class.
